Journeys

Trips that should feel visual before the scrolling starts

A cleaner home for places, movement, selected photos, and short notes — without forcing every trip into a full internal page.

This section works best when it feels like a visual index first: one strong frame, a couple of supporting moods, and only then the cards and notes underneath.

Structure

A real section, not a generic placeholder

Flexible entry point

Every journey supports a title, year, short teaser, tags, and one destination-appropriate image set.

Optional deeper layer

Use an expandable preview for quick highlights now, then swap in a dedicated internal page later only where it earns its place.

Easy to maintain

No CMS complexity required. Each journey is just a card pattern with optional details, so GitHub Pages stays simple.

How to grow this later

  • Keep the main page curated: teaser, 1–3 good photos, and a few tags.
  • Add an internal page only when a trip has enough story, images, or route notes to justify it.
  • Use expandable previews as the middle layer so the section feels alive before the archive is large.

Internal page pattern

If you later want dedicated journey pages, the cleanest path is:

  1. Main Journeys index card with teaser and cover image.
  2. Optional expandable preview for a few highlights.
  3. Dedicated page only for journeys that deserve a fuller story or gallery.

Placeholder status

Most reused mismatched images were replaced with more destination-appropriate placeholders. Any remaining mismatched support images are labeled temporary on purpose so they are easy to swap later.
